# sound-loss-calculation
four comparison calculation
MATLAB变量	对应声场	作用
data{1}     目标声场	参考标准
data{2}	    代码仿真	第一组待评价声场 设置四组数据的幅值缩放系数（新方法代码算出结果归一化了，计算则缩放到255和传统方法对其）
data{3}	    离散仿真	第二组待评价声场
data{4}	    离散扫描	第三组待评价声场 （扫描矩阵在第一行和第一列中保存了物理坐标 其余区域为声场数据）
统一精度为double，进行逐像素比较
如果出现无效值，则将其替换为0。
整段程序最核心的部分：第六部分：计算12项损失与评价指标
每次循环取出一组待评价声场：
- 第一次：代码仿真；
- 第二次：离散仿真；
- 第三次：离散扫描。
分别计算12个指标。
1. 原始差值与归一化误差 仿真声场的幅值偏大或偏小都会真实反映在误差指标中。
2. MSE：均方误差
